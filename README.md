# Universo Singular — projeto web inicial

Projeto estático responsivo desenvolvido com HTML5, CSS3, Bootstrap 5 e JavaScript.

## Páginas
- index.html — Home
- psicoterapia-individual.html
- infantil-adolescente.html
- terapia-casal.html
- atendimento-online.html

## Estrutura
- assets/style.css — identidade visual e responsividade
- assets/script.js — animações de entrada, navbar, botão voltar ao topo e validação do formulário demonstrativo
- assets/logo-universo-singular.png — imagem enviada no briefing

## Antes de publicar
1. Substituir telefone, e-mail, endereço e WhatsApp.
2. Inserir nome completo, título profissional e CRP da responsável técnica/equipe.
3. Revisar os textos conforme abordagens, especialidades e públicos realmente atendidos.
4. Trocar a imagem do logotipo por um arquivo limpo/sem elementos de captura de tela, preferencialmente PNG transparente ou SVG.
5. Conectar o formulário a um backend, e-mail, WhatsApp ou plataforma de agendamento.
6. Criar páginas de Política de Privacidade/LGPD e Termos, conforme a operação real do site.
7. Revisar acessibilidade, consentimento de cookies se aplicável e configurações de analytics.

## Como visualizar
Abra `index.html` no navegador ou execute um servidor local simples na pasta do projeto.
